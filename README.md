Коллекция простых игр и графических прототипов, написанных на **Rust**. Проект служит песочницей для отработки низкоуровневой графики без использования тяжелых игровых движков, с упором на чистую архитектуру и производительность.


## О проекте

Основная цель — написать простые игры. Вместо готовых решений используется прямая работа с пиксельным буфером через `minifb`, что позволяет полностью контролировать процесс рендеринга и лучше понимать принципы работы графики на системном уровне.

Все написаные игры находятся в `/scr/bin`.


## Как запустить

Убедитесь, что у вас установлены **Rust** и **Cargo**.

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/MaxMavr/rust_games.git
    cd rust_games
    ```

2.  Запустите игрушку проект:
    ```bash
    cargo run --bin snack
    ```


## Зависимости

*   **Rust (Edition 2024)**
*   **minifb** — минималистичная библиотека для создания окон и работы с фреймбуфером.
*   **display-info** — получение информации о дисплее для корректного развертывания окна.
*   **rand** — генерация случайных чисел для игровой логики.


## Структура

### Utils
Утилиты для работы с окном и памятью.
*   **`init_window`** — инициализация окна на весь экран с заданным FPS. Автоматически определяет разрешение основного дисплея.
*   **`pixels_buffer`** — обертка над вектором пикселей (`Vec<u32>`). Предоставляет безопасные методы для записи цвета по координатам с проверкой границ экрана.
*   **`to_screen_position`** — трейт для унификации работы с координатами. Позволяет передавать в функции отрисовки разные типы данных (кортежи, массивы, векторы), не заботясь о ручном преобразовании типов.

### Graphics
Базовые примитивы и константы для отрисовки.
*   **`vectors`** — структура `Vector2` и макрос `vector2!` для удобного создания точек и направлений.
*   **`size`** — структура `Size` и макрос `size!` для хранения размеров объектов.
*   **`rectangles`** — структура `Rectangle` для описания областей. Используется для определения границ буфера и проверки коллизий.
*   **`font_bdf`** — структура `FontBDF` и парсер растровых шрифтов формата [BDF](https://en.wikipedia.org/wiki/Glyph_Bitmap_Distribution_Format). Позволяет подключать готовые гарнитуры, например, из [этой коллекции](https://github.com/Tecate/bitmap-fonts).
*   **`colors`** — палитра часто используемых цветов в формате `u32`.
